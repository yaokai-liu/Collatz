\section{Homomorphisms That Preserves Logarithm Measure Between Source Value Set}~\label{sec:homomorphisms-that-preserves-logarithm-measure-between-source-value-set}

Let's back consider the density of $\mathbb{F}_{n}(b)$.
From Tao's result\cite{tao2022orbitscollatzmapattain}, the logarithm density of $\bigcup_{n=0}^{\infty}\mathbb{F}_{n}(1)$ is $1$.
Suppose there's another number $b$ that $b \not\rightsquigarrow 1$, then $\bigcup_{n=0}^{\infty}\mathbb{F}_{n}(b)\cap\bigcup_{n=0}^{\infty}\mathbb{F}_{n}(1) = \varnothing$, that means the logarithm density of $\bigcup_{n=0}^{\infty}\mathbb{F}_{n}(b)$ will be $0$.
But if they are some homomorphic that keeps the logarithm measure, then the logarithm density of $\bigcup_{n=0}^{\infty}\mathbb{F}_{n}(b)$ will not be $0$.
That means, with this kind of homomorphic, to keep the zero logarithm density, $\bigcup_{n=0}^{\infty}\mathbb{F}_{n}(b)$ must be "finity layers", i.e. $\exists N > 0$, such that $\bigcup_{n=0}^{\infty}\mathbb{F}_{n}(b) = \bigcup_{n=0}^{N}\mathbb{F}_{n}(b)$.
Or more mathematically, $\bigcup_{n=0}^{\infty}\mathbb{F}_{n}(b)$ has a finity cover.
With this, consider the last layer $\mathbb{F}_{N}(b)$, suppose it's not empty.
The $\mathbb{F}_{N}(b)$ will all be primitive sources.
From \cref{sec:distribution-of-multi-step-collatz-primitive-source}, for $(3,2,1)$, the primitive source will be all times of $3$.
But from \cref{prop:layers-of-reduce-space-and-source-value-set}, the value sould follow the irterative fomula $f_{k+1} = 4f_{k} + 1$, which must generate non-primitive source value. It means we can trace back to $N+1$ layer.
That requires $N = 0$ and $b \in \mathbb{S}$. Sum up, if $b \not\rightsquigarrow 1$, then $b \in \mathbb{S}$.
But now consider $b_1 = 3b + 1$, $b_1 \not\rightsquigarrow 1$, and $b_1 \not \in \mathbb{S}$, that's a confliction.
Thus, if there a homomorphism that keeps the logarithm measure, then there's no one can escape from $1$.

Thus, if we can prove there is a homomorphism that keeps the logarithm measure between those source value set, we proved \cref{conj:source-value-of-1-cover-all-odd-numbers}, which equivalents to the classic Collatz conjecture.
