\begin{abstract}
    This paper explores the algebraic and dynamic properties of general Collatz systems governed by the relation $a_{k+1}\cdot\beta^{\val(a;k+1)} = \alpha\cdot a_{k} + \gamma$. We discover the periodic properties of the reduce sequences and subsequently construct a hierarchical model for the corresponding source value sets. Furthermore, we prove that the underlying algebraic structure of these sets exhibits strong rigidity, remaining invariant under a specific class of arithmetic densities; this establishes that the densities of these source value sets are proportional. Leveraging these invariants, we classify the source value landscapes for a simple class of general Collatz systems, thereby offering measure-theoretic insights toward the original conjecture. Finally, we formalize the Collatz system as a $(\sigma, \tau)$-derivation over a groupoid structure. This formulation reveals a connection between general Collatz systems and the power difference problem, thus providing a dynamical systems perspective for Diophantine approximation analysis.
\end{abstract}
